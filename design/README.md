# Design boards

- screens/  PNG render of every board (1440x900)
- html/     static HTML of every board; open in a browser. Overlays embed Main.html in an iframe.
- source/   original canvas files (*.dc.html + canvas.json). These need the Design canvas runtime to open; html/ does not.

Boards: Main, StartWork, Modes (help overlay), Inbox, Issues, PRs, Reader, PROverlay, Repos, Colors, Agents, AgentsMore, AgentsMore2, FirstRun, Empty, Resume, History, Diff.
Sample data is invented. Agent icons are placeholder tiles.
