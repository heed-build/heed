# heed brand pack

Mark: owl on a branch. Wordmark: JetBrains Mono Bold, lowercase, static (no cursor in print/static use).
Tagline: Keep an eye on every agent.

## Colours
ink #0e0f11 · ivory #dfe3e8 · signal amber #f0a53a (on light: #c97d12) · slate tones inside the owl

## Size ladder
>= 64 px: full owl on branch. <= 32 px and in-app small: cropped head (same face as the full owl). 16 px / menu bar: mono head (template, uses currentColor).

## Contents
- logo/: owl full + head (dark, light, mono), wordmark outlined (dark, light)
- icons/png: app icon tile 16..1024. icons/macos: heed.iconset + heed.icns
- icons/menubar-template.svg: monochrome template image for the menu bar
- github/: org avatars (dark, light). social/: 1280x640 social preview
- animated/: CSS-animated owl heads (idle, working, asking, blocked, sleeping) and full owl
- fonts/: JetBrains Mono 400 and 700 (SIL OFL 1.1)

Logo SVGs embed their gradients and reference symbols via <use>; open them in a browser or any modern SVG viewer.
