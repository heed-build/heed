# The tutor

`:tutor` opens the tutor: lessons done for real, in the same window, on made-up data. Nothing you do there touches
your real sessions, which keep running underneath (the Dock and the menu bar stay live). `t` on the first-run screen
starts it too.

![The tutor: a TUTOR banner under the title bar, and the current lesson's steps ticked off as they are done](../images/shots/getting-started/tutor.png)

Each lesson lists its steps and ticks them off as you do them: the tutor watches what changes in the app, so there is
nothing to confirm. Keys in the lessons are shown as you have them bound.

| Key | |
|---|---|
| `⌘]` | Next lesson |
| `⌘[` | Previous lesson |
| `:tutor` | Leave the tutor (or click **Leave** in the banner) |

The lesson you reached is remembered for next time.
