# The tutor

`:tutor` (or `t` on the first-run screen) opens the tutor: lessons done for real, in the same window, on made-up
data. Nothing you do there touches your real sessions, which keep running underneath.

Each lesson lists its steps and ticks them off as you do them. `⌘]` and `⌘[` move between lessons, and `:tutor`
leaves. The first lesson is about the views and switching between them.
