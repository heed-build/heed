# Heed

Keep an eye on every agent.

Heed is a native macOS app for working with coding agents. It runs agents and shells in real terminals, gives each
task its own git worktree, and keeps the GitHub issues and pull requests around that task in view. It tells you which
agent needs you, and it gets you there in a keystroke.

- **Sessions**: an agent, its terminals and its worktree, with a live state (working, blocked, asking, done).
- **Keyboard first**: vim-style modes, everything one or two keys away.
- **GitHub, through `gh`**: your inbox, issues and pull requests, and review feedback fed back to the agent.
- **Start work from anywhere**: describe a task and Heed picks the repo, names the branch, makes the worktree and
  starts the agent.

New here? [Getting started](getting-started/index.md) installs Heed and walks through the first run, and
[the tutor](getting-started/tutor.md) teaches the keys in a sandbox.
