# Mac shortcuts

The standard Mac shortcuts work in every mode, including INSERT, where a terminal takes your other keys. heed binds the
`⌘` keys below. It passes every other `⌘` key to the app menu, as any Mac app does.

| Key | |
|---|---|
| `⌘W` | Close the window. With the [menu bar item](../outside-the-window/menu-bar.md) on, heed and its agents keep running. Without it, closing the window quits. |
| `⌘Q` | Quit. With agents running, heed asks first and lists them. |
| `⌘H` | Hide heed |
| `⌘M` | Minimise |
| `⌘,` | Settings |
| `⌘N` | Start work (also `o`) |
| `⌘/` | Every key (also `?`) |
| `⌘⇧T` | The [tutor](../getting-started/tutor.md)'s picker |
| `⌘.` | Leave the tutor at once |

## In INSERT

In INSERT, the terminal gets everything except heed's own few keys. `⌘C`, `⌘V` and the other `⌘` shortcuts that heed
does not bind go to the terminal.

The way back to NORMAL is `⇧⎋` or `⌃\`. See [Modes](../concepts/modes.md).

## In text fields

In every field heed takes typing in, `⌘A` selects all, `⌘V` pastes and `⌘⌫` deletes back to the start of the line. See
[Start work](../start-work/index.md) for the full list.
