# Mac shortcuts

The standard Mac shortcuts work in every mode, even with a terminal taking your keys:

| Key | |
|---|---|
| `⌘W` | Close the window. With the [menu bar item](../outside-the-window/menu-bar.md) on, Heed and its agents keep running. |
| `⌘Q` | Quit. With agents running, Heed asks first and lists them. |
| `⌘H` | Hide Heed |
| `⌘M` | Minimise |
| `⌘,` | Settings |
| `⌘/` | Every key (also `?`) |

Other `⌘` shortcuts Heed does not bind go to the app menu as in any Mac app. In INSERT, everything else (`⌘C`, `⌘V`
and the rest) goes to the terminal.
